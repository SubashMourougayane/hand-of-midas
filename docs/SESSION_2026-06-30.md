## Decisions Made

- **Soft-retire SDR-001 + ema_cross**, don't remove. CLI defaults flipped to fib_v2.
- **Schema migration via ALTER TABLE IF NOT EXISTS** in `schema.sql` (not full alembic versioning) — keeps idempotent + simple.
- **`FibV2State.clone() returns self`** — explicit perf override. Safe because strategy is single-threaded.
- **Engine modification**: orders with `intended_entry_bar == bar.timestamp` fill same tick (research's `op[k+1]` semantics). Strategy emits these AFTER computing risk from bar.open of the entry bar.
- **Bracket SL/TP outcome snapping**: -1.0R / exact tp_R (research convention, NOT close-based). Avoids ambiguity in net_R.
- **Two-stage entry**: signal bar k queues `pending_entry`; bar k+1 finalizes Order using bar.open. This matches research's `entry_price = m5.open[k+1]`.
