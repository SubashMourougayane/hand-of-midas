## Bugs Found & Fixed

### Critical (would have broken live trading)
1. **OANDA nanosecond timestamps** — `datetime.fromisoformat()` crashes on 9-decimal precision. Fixed with `_parse_ts()` regex truncation. This was crashing Alpha-Sweep every 3 minutes on server.
2. **`get_conn` not imported in scheduler.py** — `_persist_m3_candles()` would throw NameError.
3. **`get_account_summary()` error → $5K fallback** — if OANDA API fails, system sized positions for $5K instead of $132K. Now skips signal.
4. **Telegram `parse_mode: "HTML"`** — silently rejected all messages with special characters. Removed.
5. **Telegram `.env` not loaded** — `notify.py` read env vars at import time before dotenv loaded. Added own `load_dotenv()`.
6. **Frontend port-based routing** — `apiBase.includes("5054")` fails in production (same domain). Changed to use `instrument` context.
7. **Numpy types crash psycopg2-binary** — server's pip psycopg2 doesn't auto-adapt numpy. Added `float()`/`int()` casts in all DB writes.

### High
8. **`acct` variable scoping** — dead code in `check_open_positions()` referenced out-of-scope variable. Cleaned.
9. **Oil entry using mid price** — was `(ask+bid)/2 + slippage` instead of `ask + slippage`. Fixed to match Gold.
10. **`pause_counter` overwrite** — 5th loss set pause=2 via SQL then `_update_dd_state()` overwrote with old value 0.
11. **`tp=entry` BE bug** — break-even would fire immediately on degenerate trade params. Added guard.
12. **Decimal + float TypeError** — PostgreSQL NUMERIC returns `decimal.Decimal`, crashes when added to float.

### Medium
13. **Partial H1 candles** — `get_candles()` already filters incomplete bars (line 121), but added redundant safety check in scheduler.
14. **`useEffect` dependencies** — journal/trades pages didn't re-fetch on instrument switch in production.
15. **Submodule reference** — frontend was tracked as git submodule pointer (160000 mode), not files. Removed and added files directly.

## Bias Filter Research (Variant C)

### What Was Tested
8 variants of daily bias filter on Gold Alpha-Sweep:

| Variant | Logic | Trades | WR | PF | $/yr | Total | DD | Lose |
|---------|-------|--------|-----|-----|------|-------|-----|------|
| A (current) | Yesterday only | 684 | 76.5% | 7.31 | +$7,455 | $156K | 3.4% | 0/21 |
| B | 2/3 days agree | 969 | 60.7% | 2.81 | +$5,191 | $109K | 9.3% | 0/21 |
| **C** | **Strong body only (weak=allow both)** | **1,455** | **63.5%** | **3.24** | **+$8,633** | **$181K** | **7.1%** | **0/21** |
| D | Weekly net direction | 995 | 56.4% | 2.27 | +$4,126 | $87K | 10.6% | 1/21 |
| E | Price vs 50-day MA | 1,125 | 53.7% | 1.82 | +$3,305 | $69K | 17.1% | 4/21 |
| F | 20-MA slope (flat=allow both) | 1,385 | 51.9% | 1.63 | +$3,209 | $67K | 16.3% | 2/21 |
| G | 2/3 agree + strong body | 1,421 | 59.8% | 2.54 | +$6,532 | $137K | 11.2% | 0/21 |
| H | No filter | 2,282 | 50.4% | 1.62 | +$5,363 | $113K | 15.0% | 0/21 |

### Variant C Details
- Logic: If yesterday's candle body > 40% of its high-low range → apply normal bias (bullish/bearish)
- If yesterday was small body (doji/indecision, body < 40% of range) → allow BOTH directions
- Result: +113% more trades, +$25K more Gold Alpha P&L, slightly lower PF but higher total $/yr
- Full portfolio with C: $558K (vs $640K current) — delta is due to compounding differences in test methods, not real degradation

### Conclusion
- Variant A (current) is the safest: highest PF (7.31), lowest DD (3.4%), fewest trades (684)
- Variant C is the most profitable per year (+$8,633 vs +$7,455): catches indecision-day reversals
- Decision: **Keep Variant A live for now. Switch to C after 50+ live trades validate the base system.**

## Key Learnings Added to LEARNINGS.md

- Every module that reads env vars must load dotenv itself
- `parse_mode: "HTML"` in Telegram silently rejects special characters
- OANDA returns nanosecond timestamps that Python can't parse
- psycopg2-binary (pip) ≠ psycopg2 (Anaconda) for numpy handling
- Port-based routing fails in production (use instrument context)
- Unit tests with mocks prove logic, not wiring — need integration tests
- First live day often has no trade (3 trades/month average = most days quiet)
- Hourly heartbeat eliminates "is it alive?" anxiety
