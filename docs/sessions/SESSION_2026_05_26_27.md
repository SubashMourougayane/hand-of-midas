## Critical Investigation: Why No Trades on May 26

### Gold
- Sweep at 07:00 UTC H1 bar (low $4,521.64, close $4,538.36 — valid sweep)
- Engulfing window: 07:00-09:00 UTC
- Near-miss at 08:21 UTC: `cb=$4,527.75 vs pb=$4,527.77` — missed by **$0.02**
- With $0.10 tolerance → WOULD HAVE TRADED
- Additionally: EC2 service crashed at 10:47 UTC (timedelta import bug)

### Oil
- 3 valid sweep bars: 09:00, 12:00, 18:00 UTC
- ALL THREE had **strict bearish engulfing** (not even near-miss!)
- Engulfing at: 09:15, 12:09, 18:48 UTC
- **But:** Oil service started late (10:22 UTC, missed 09:15)
- **And:** OANDA 522 errors prevented scheduler from getting H1 data for 12:09 and 18:48
- Zero `[SWEEP]` messages in Oil scheduler logs despite polling all day
- Root cause: `get_candles()` returns empty on 522 → scheduler silently skips

### Lessons
1. OANDA Practice API is unreliable — lost 4 real trades in one day
2. Never deploy during trading hours (timedelta fix crashed Gold at 10:47)
3. MT5/DWX eliminates data reliability issues completely
4. The engulfing tolerance would have caught Gold's near-miss
