## Critical Bugs Found & Fixed

1. **MT5 fill mode IOC vs FOK** — all orders failed until EA recompiled with FOK
2. **Scanner scan_end_hour overflow** — window 16-20 scan extended to hour 26 (past midnight), causing trades during market close
3. **Gold Macro SSE stream leaked Micro signals** — stream.py had unfiltered query
4. **Backtest date column was DATE type** — truncated timestamps, sessions showed 0 (changed to TEXT)
5. **SSE backtest result too large** — 800KB JSON payload failed, switched to "done" signal + DB load
6. **_hour_past 22hr window** — caused false positives in midnight wrap, fixed to 12hr

## Key Learnings

1. **Rolling windows generate 3.5x more trades than fixed Asia** — same PF, more opportunity
2. **The edge is NOT Asia-only** — Overlap (43%) and London (34%) dominate entries
3. **Backtest ≠ live exactly** — 22% fewer trades live due to point-in-time vs retrospective scanning
4. **SSE > polling** — eliminated timeout issues for long backtests, reduced server load
5. **DB column types matter** — DATE silently truncates timestamps, breaking session classification
6. **MT5 fill mode is broker-specific** — JustMarkets requires FOK, code had IOC from OANDA days
7. **Midnight wrap is complex** — _hour_past logic needed careful testing, 22hr window caused bugs
8. **DWX race condition on close** — last_response.json gets stale reads if commands fire rapidly
9. **Signal isolation requires filtering in BOTH state.py AND stream.py** — easy to miss the SSE route
10. **Fresh $5K/year backtest ≠ compounded live** — $1.36M is sum of 20 independent years, not compound growth
