## How to find something

- **"Why did trade X happen this way?"** → [trades/](trades/) for postmortem,
  or [postmortems/](postmortems/) for day-level forensics.
- **"What's the current state of parity?"** → [parity/PARITY_AUDIT_2026-06-19.md](parity/PARITY_AUDIT_2026-06-19.md).
- **"How does Filter N work?"** → [filters/FILTER_N_*.md](filters/).
- **"What did we ship today?"** → [sessions/](sessions/) (latest file).
- **"Is this a known bug?"** → [bugs/](bugs/).
- **"How does the deploy work?"** → [ops/](ops/).
- **"Why did we choose X over Y?"** → [architecture/](architecture/).
