## Decisions Made

- **Warmup replay approach** over state-serialization-to-disk. Simpler, deterministic, uses same code path as engine loop, only ~30 lines. Events emitted during warmup are discarded (not persisted, not fed to callbacks).
- **Filter bar inside Trades pane (collapsed by default)** vs top-of-page global. Kept filter state global so KPIs/equity/calendar recompute with filter, but visually attached to Trades where it belongs.
- **Signals removed from Live page.** Live is "what am I holding right now" — signals belong on dedicated `/signals` page with expandable checklist decoder.
- **$ PnL from `raw_features.pnl_usd` when present, else `net_r × risk_units × contract_size`.** Combined-replay runs write the sizer-aware value; older BT runs get 1.0-lot fallback.
- **Bash detached loop + Claude cron redundancy** for overnight monitor. Bash loop uses `setsid nohup` so PPID=1, survives Claude session death. Cron is belt-and-suspenders.
- **Removed SignalMiniChart** — recharts custom-shape candlestick didn't render properly. Kept just the animated GateChecklist. Chart integration deferred.
